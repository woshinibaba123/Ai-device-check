# 模块流程库

界面“按模块选择预设流程”选择模块和流程，填写参数，预览步骤后点“使用此流程”，再开始测试。

JSON 中包含版本、模块、流程 ID、参数、步骤、App/H5 来源及验证状态。这里的流程是可加载的 AI 执行目标，不等同于无需模型的确定性脚本，也未声称全部通过真机验证。已确认的标准模块仍由原脚本库管理。

H5 来源采用当前项目配置的 portal-tele-270 源码快照，路由和组件文件已核对。静态源码能确认页面存在，不能确认当前账号的权限、入口可见性、线上版本或业务数据。入口不可达时记录受阻，不虚构定位。

模块包括门店和设备、我的与设置、H5 页面与记录，以及原有呼叫取消草案。呼叫取消涉及真实业务操作，保留原草案的执行约束和待验证状态。

新增流程：编辑模块 JSON，保证 ID 唯一，参数采用 `{{key}}`，来源使用 `app:` / `h5:` 相对源码路径。不要保存账号密码、密钥、设备截图或运行期元素 ID。步骤中的 H5 操作必须通过 WebView 当前 DOM 定位。
